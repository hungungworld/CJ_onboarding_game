# ONLYONE 레시피를 찾아라: 햇반 30주년 타임캡슐

CJ제일제당 신입 온보딩용 웹 방탈출 게임 프로토타입 (비공식 포트폴리오)

## 실행
```bash
node tools/serve.js
```
브라우저에서 http://localhost:5173 을 엽니다.
서버 없이 파일만 올리면 되는 정적 사이트라서 Vercel에 폴더째 올리면 바로 공개 링크가 생깁니다.

> `index.html`을 더블클릭해서 여는 방식(file://)은 브라우저에 따라 이미지·스크립트가 막힐 수 있으니 위 방법을 쓰세요.

## 구성
| 파일 | 내용 |
|---|---|
| `js/content.js` | 퍼즐 문구, 정답 해시, 힌트, 등장인물, 말풍선 화자, 안내 팝업 문구 (내용 수정은 여기서만) |
| `js/game.js` | 게임 엔진: 장면 전환, 자물쇠 4종(입력·다이얼·핀·조각), 힌트·벌점, 저장, 수료증, 모션 엔진, 안내 팝업 |
| `css/style.css` | 디자인. 맨 아래에 텍스트 배치 규칙과 접근성 색이 모여 있음 |
| `assets/` | cj.co.kr에서 받은 로고·브랜드 카드 28종·연혁 사진 |
| `tools/hash.js` | 정답을 바꿀 때 해시 만들기: `node tools/hash.js 새정답` |
| `tools/serve.js` | 로컬 미리보기 서버 |

## 서체와 로고
- 서체: **CJ ONLYONE** (cj.co.kr에서 쓰는 웹 글꼴). `assets/fonts`에 300·400·600·700 굵기를 넣어 함께 배포해서, CJ 서체가 없는 PC·휴대폰에서도 같은 글꼴로 보입니다. 제목은 700을 씁니다.
- 로고: cj.co.kr 상단 로고 원본 SVG를 그대로 씁니다.
  - `assets/ci/cj_logo_black.svg`: 검은 글자, 밝은 상단바용
  - `assets/ci/cj_logo_white.svg`: 흰 글자, 시작 화면(사진 위)용
- CJ제일제당 제출·시연용 비공식 포트폴리오라서 CJ 자산을 그대로 썼습니다. 다른 곳에 공개할 때는 서체·로고 사용 권한을 먼저 확인하세요.

## 문구를 고칠 때
- **팝업**은 `lines: [...]` 줄 배열로 씁니다. 줄끼리 글자 수 차이는 30% 이내로 맞춥니다.
- **본문**(방 소개, 증언, 단서, 말풍선)에는 줄바꿈을 넣지 않습니다. 넣어도 화면에서 무시되고, 너비에 맞춰 자동으로 감깁니다.
- **대사**는 `{ who: "블라썸", text: "..." }` 형태로 쓰면 말풍선으로 나옵니다. 따옴표는 쓰지 않습니다.
- "20개가", "+1분", "CJ제일제당" 같은 묶음은 자동으로 끊기지 않게 처리됩니다.

자세한 규칙: [`../ui-text-layout-rules.md`](../ui-text-layout-rules.md)
